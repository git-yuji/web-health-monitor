# Web Health Monitor

Webサイトの稼働状態を定期的に確認し、結果を記録するモニタリングツールです。

## 目標

単発のサイト診断だけでなく、時間による変化や異常に気づけるツールを目指します。

## MVPで実装する機能

- URLの登録
- HTTPステータスの確認
- 応答時間の計測
- SSL証明書の有効期限確認
- 診断結果の保存と履歴表示

## 将来追加したい機能

- DNS・メール設定の確認
- セキュリティヘッダーの確認
- 異常時の通知
- 複数サイトのダッシュボード

## 使用技術

- TypeScript
- Vite
- Tailwind CSS

データ保存やバックエンドの技術は、MVP実装時に決定します。

## セットアップ

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```
